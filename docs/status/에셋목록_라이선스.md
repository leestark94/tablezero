## 직접 제작
- 302호 전체 메시: `blender/scripts/build_room302.py` (절차적 모델링, 자체 제작)
- 욕실/현관 타일 텍스처: Unity 빌더 절차 생성 (`gen_*`)
- 혈흔·신발 자국·정산 출력물·이웃 창문 텍스처: `TZProcTextures.cs` 코드로 생성 (`gen_bloodpool`, `gen_bloodsmear`, `gen_bloodspatter`, `gen_shoeprint`, `gen_printdoc`, `gen_nightwin`) — 외부 소스 없음
- 증거 표지 숫자: Noto Sans KR(OFL) 텍스트 메시
- 로컬 LLM: Ollama 모델은 런타임 다운로드(저장소 미포함). qwen3 Apache-2.0, kanana-1.5 Apache-2.0, gemma 계열 Gemma 약관 — 출시 전 재확인 필요
- **EXAONE 계열은 비상업 라이선스라 사용 금지**
