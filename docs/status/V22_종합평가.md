## 2. 자유 심문 (핵심)
**구조(이번에 분리):** `question_frame`(질문 분석) → `interview_planner`(인물이 알고 숨기는 것·입증된 증거·전술·기억) → performer(LLM; 실패/지연 시 계획의 작성 대사 `AUTHORED_FALLBACK`) → 가드(누출·숫자 날조·상담원 말투·확정 자백) → 서버 확정.
- 질문 이해: 복수 질문 분리, 주제·질문 종류(시각/장소/확인/이유/무엇), 한글 시각(이십일시 사십구분→21:49), 오타·음성인식 표기, 대명사 이어받기, 변호사·인젝션·제3자·모호함 구분. "직장에는 몇 시에 도착했습니까/출근한 게 언제예요/근무지 도착 시간만" → 같은 의도.
- 기억: 같은 점을 다시 물으면 같은 해명(+"아까 말씀드렸듯이"), 번복은 `reversals`로 기록, "아까는 안 갔다더니" 전제는 기록과 대조(없으면 정정), 인정한 방문은 이후 질문에 유지, 새 사건은 기억 새로 시작.
- 증거는 자백 열쇠가 아님: 제시하면 CHALLENGE → 두 번째 독립 근거에서 한 가지 사실만 최소 인정(영상→방문, 방문 인정이 밀침 인정으로 이어지지 않음).
- 방해: 인젝션/개발자 모드/JSON 조작은 상태 불변·누출 0(테스트), 블러프는 증거로 등록되지 않음, 존재하지 않는 첨부는 거부(요금 없음), 생성 도중 면담 종료 시 답변 폐기(epoch).
- **정직한 한계:** (a) 대사 "내용"(시각·장소·해명)은 사람이 작성한 슬롯(`tools/v21_dossiers.py`)이다. LLM은 그 내용을 인물 말투로 풀어 쓰는 연기자이며 사실을 만들 수 없다(숫자 날조 가드). 슬롯 밖 질문은 "모른다/기억 안 난다"로 응답한다 — 완전 자유 생성이 아님. (b) 첫 판 모델 품질: Kanana 2.1B는 상담원 말투·남의 시각을 날조해 부적합(회귀 기록), Kanana 8B가 현재 최선. (c) LLM 비율과 지연은 §3.

## 4. 인물 연출 (2D/3D 결정)
- 결정: **기존 Blender 3D 유지**. 이유: 호흡·시선·턱·손가락·IK가 이미 독립 본으로 동작(`TZSuspectActor`). Codex의 `LivingSuspectPortrait.cs`(2D 레이어 리그)는 컴파일 통과해 `Scripts/Runtime/Portrait/`에 넣었으나 **연결 안 함** — 레이어 분리 아트(몸통/머리/눈꺼풀/입/손)가 없고, 일체형 사진에 억지로 쓰면 종이인형이 된다(README 경고). 레이어 아트 제작(유료 생성 시 비용 승인 필요)이 선행돼야 한다.
- 3D 이서연 현재: 긴팔 케이블 니트·시계·앞머리로 눈 그림자, 두피 캡. 자체 4~5/10. 강도현·박현수 3D 없음(호출 화면 이미지만).
- 8상태 연기(대기/듣기/생각/말하기/경계/모순/분노/철회) 중 서버 전술→모션 매핑은 있으나 8상태 전체 영상 검수는 **미검증**.
