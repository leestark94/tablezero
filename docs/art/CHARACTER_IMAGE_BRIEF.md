# 캐릭터 이미지 브리프 (3D 전 단계)

> 순서: **이미지 생성 → 사용자 승인 → 승인된 이미지로만 3D(Tripo)**. 승인 전에는 3D 생성 금지.
> 기준 시안: `references_images/INTERROGATION_TARGET_VISUAL.png`(이서연), `references_images/SCENE_302_TARGET_VISUAL.png`(1인칭 손).
> 공통 화풍: 실사, 시네마틱하지만 과장 없는 한국 일상 인물, 무채색 회색 배경, 균일한 스튜디오 조명(3D 변환용 — 강한 그림자·역광 금지), 글자·로고·워터마크 없음.

## 산출물 (인물당)
1. 턴어라운드 시트: 정면 / 측면 / 후면, 릴랙스 A포즈, 전신, 같은 키·같은 스케일, 한 장에 가로 배치
2. 얼굴 클로즈업: 정면 + 3/4, 무표정에 가까운 피로한 얼굴 (심문실 클로즈업용)
3. 승인 후에만 → multiview-to-model → 텍스처 → 리깅

## s2 이서연 (29, 화장품 회사 마케팅팀 대리, 피해자와 같은 팀) — 시안 있음
- 시안 유지: 가운데 가르마 긴 흑발(가슴 아래), 짙은 갈색 꽈배기 니트(오버핏), 왼손목 은색 메탈 시계
- 추가: 짙은 회색 슬랙스, 검정 단화. 화장 옅음, 눈가 피로
- 시안의 고개 숙인 자세는 심문 연출용 애니메이션으로 재현 (모델은 A포즈)

## s1 강도현 (31, 물류센터 주간 관리직, 피해자의 전 연인) — 시안 없음, s2 화풍에 맞춤
- 짧은 흑발, 면도 덜 함, 회색 작업 점퍼 + 무지 티셔츠, 청바지, 운동화
- 체격 보통~다부짐, 퇴근길 그대로 온 느낌

## s3 박현수 (46, 배달 대행 라이더) — 시안 없음, s2 화풍에 맞춤
- 그을린 얼굴, 희끗한 짧은 머리, 검정 패딩 라이더 재킷, 카고 바지, 낡은 운동화
- 헬멧은 손에 들지 않음(별도 소품)

## 1인칭 손 — 시안 있음
- 시안 유지: 맨손(장갑 없음), 어두운 남색 재킷 소매, 오른손에 검정 택티컬 손전등
- 시트: 오른손(손전등 쥔 자세) 1인칭 시점 + 3/4 측면, 왼손(문틀 짚는 펼친 손) 1인칭 시점
- 장갑(G키)은 같은 손 메시에 니트릴 머티리얼 교체로 처리

## 승인 체크
- 한국인으로 자연스러운가 / 나이·직업이 옷차림에 드러나는가 / 시안과 같은 사람인가(이서연) / 세 사람 화풍이 같은가
- 손가락 개수·관절, 시계 위치, 좌우 반전 오류 없음
