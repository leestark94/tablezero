# 실제 AI 용의자 / 한국형 심문 / 자유 타이핑 / 음성

## 지향점
가장 어렵고 가장 비싼 기능. 우리가 파는 것은 음성 인식 기술이 아니라 **그 사람의 지식·이익·불안·관계·기억을 유지하며, 플레이어가 어떤 질문을 했는지에 따라 스스로 대응 방법을 바꾸는 인물**이다. AI가 매번 모범답안처럼 길게 설명하면 실패

## AI 데이터 보안 경계
1. `CASE001_CANON_LOCKED.json`은 서버 전용, Unity로 절대 복사 금지
2. 용의자별 PersonaProfile + 과거 직접 경험한 사실 + 기존 진술 + 다른 인물에게 실제 전달받은 사건 + *형사로부터 공개된 증거*만 모델에 제공
3. `PoliceKnown`과 `SuspectBelievesPoliceKnows`를 구분. 범인도 경찰의 비공개 수사 결과를 모른다
4. NPC 정보 노드마다 `source`, `learned_at`, `information_channel`, `belief_confidence`, `can_mention`을 기록
5. 정답은 LLM이 못 바꾼다. LLM은 **대답·주장·감정·행동 제안**만, WorldState/CaseTruth는 검증 가능한 서버 코드만 변경
6. AI가 ‘칼에 지문 있다’고 말해도 이것은 주장일 뿐. 실제 지문 감정 데이터가 없다면 UI에 확인 사실로 생성 금지
7. `claims`, `verified_facts`, `forensic_results`, `authorized_autonomous_actions`는 별도 스토어
8. 장기 기억: 최근 10~14턴 + 이전 확정 주장 장부 + 동기요약 + 타임스탬프. 요약을 다시 검증하고 비공개 기억 누출 테스트

## 각 인물의 고유한 전략
- **강도현(s1)**: 전 남자친구, 숨길 이유가 있다. 새 교제 관련 사생활은 감추고 살인 혐의엔 격렬히 반응할 수 있다. 뻔한 ‘욱하는 범인’ 코드로 사용 금지
- **이서연(s2)**: 친구·직장 동료, 진범이지만 모든 질문에 뻔한 당황/눈물 금지. 경찰에 드러난 사실의 **범위**를 계산해 부분 인정과 질문 되돌리기를 사용할 수 있다
- **박현수(s3)**: 옆집, 신고 관련 목격 경험과 임대 관련 비공개 문제. 까칠하고 방어적이어도 범인이라는 의미가 아니다

## AI의 사고와 응답은 구분
모델 입력: 인물의 직접 기억, 현재 조사 상황, 형사가 제시한 자료의 실제 공개 범위, 그간 진술, 플레이어의 질문, 대화 방식, 가능한 행동 ID
모델 구조화 출력: `utterance`, `reply_mode`, `motion_id`, `asserted_claim_ids`, `new_unsupported_assertion`, `request_external_action` (기존 V10 계약 유지)
서버: JSON 스키마 검사 → 참조 ID 허용목록 검사 → 대사 품질 검사 → 물리 연출 가능한지 확인 → 고정 진실과 기존 주장에 따른 부작용 기록 → 플레이어에게 안전한 데이터만 반환
추가 권장 필드(후속 버전): `thought_strategy`(서버 전용, 모델의 장황한 사고과정 요청 금지), `silence_duration_ms`, `repair_of_claim_id`, `belief_update_proposals`, `delivery_style` (각자 JSON 스키마 업데이트 및 버전 관리 후에만 적용)

## 질문 입력의 시간 비용
권장 초깃값: 추천 질문 14초 / 직접 자유 텍스트 24초 / 마이크 자유 질문 24초
- 차감 대상: **면담 집중 시간(900초 기본)**. 사건의 전체 행동 기회나 실제 사용자의 타이핑·네트워크 지연 시간이 아님
- 서버 LLM 실패, STT 실패, 검증 불합격, 사용자가 음성 원문을 수정하거나 취소한 경우에는 시간 차감 0
- 클릭 추천 문항도 AI에게 *의미상 동일한 질문*을 보내되 질문의 입력 방식만 구분. 만능 자동 정답 버튼 금지
- 불리한 증거 제시, 반복 추궁, 상대 말을 끊기, 책상 치기 등은 별도 시간/절차 비용을 초래하고 결과가 저장됨
- 14/24초는 프로토타입 수치. 실제 한국어 속도와 플레이테스트 반응을 측정해 수정. 플레이어가 읽는 동안 실시간 카운터를 강제하지 않음
- 디스크/프레임/LLM 지연은 무료. 공정하지 않은 ‘API 느려서 타임아웃’은 금지
- **초읽기 HUD 상시 노출 금지**. 면담 파일/녹음 헤더를 열 때 예상 남은 인터뷰 시간으로만 표시

## 마이크 질문 파이프라인
1. Push-to-talk → 로컬 WAV 녹음 (서버 측 API 키 없음)
2. 인증된 backend STT (상용 API는 명시적 사용자 승인, 또는 사용자가 설치한 로컬 faster-whisper 모델)
3. 인식한 한국어를 **플레이어가 수정할 수 있는 편집창**에 보여줌. 확인 전엔 NPC에게 보내지 않고 비용 없음
4. 확인 누르면 `input_mode=voice`, `action_id`, `question`, `evidence_id`, `transcript_confirmed=true`
5. STT/AI 지연 중 용의자는 조용히 손가락을 움직이거나 호흡. 새 사실 암시하는 입모양 자동 재생 금지
6. AI 응답 수신 시 서버 검증→실제 클립/음성/자막 동기화→수사 기록 저장. TTS가 부자연스러우면 립싱크까지 거짓으로 완성 선언 금지
7. 음성 녹취 사용 고지·삭제 선택·외부 전송 알림과 민감한 대화 보관 정책 별도 마련

## 실제 대사의 완성도
모든 **인게임 대사 줄 끝의 마침표(.) 삭제**. 이 규칙은 일반 문서·코드·URL·소수점이 아니라 **대본과 자막**에 적용
- 형사·용의자가 쓰는 한국어는 실제 생활 말투. 존댓말→말 놓음은 일관된 관계·상황 변화에만
- “형사님, 당신은 제가 진실을 말한다는 걸 알아야 합니다” 같은 번역투 금지
- 수사 질문은 길게 설명하지 않는다. 예) “9시 34분에 통화한 건 맞죠?”
- 멍한 침묵은 ‘…’라는 텍스트만 출력하는 게 아니라 숨, 어깨, 시선, 소품 움직임으로 표현
- NPC가 거의 매 턴 “뭔가를 감추고 있습니다”와 같은 메타 설명을 쓰지 않게 하고, 획득 가능한 것은 **대사·관찰·녹음파일**만
- 사람마다 분노 방식이 다르다. 혼잣말, 반복되는 조사 불쾌감, 갑작스런 항의도 감정만으로 진범 단서가 되어선 안 됨

## 한국어 대사 짧은 샘플 (최종 녹음본 아님)
형사: “21시 34분에 전화한 건 맞죠?”
이서연: “네, 통화했어요, 그건 맞아요”
형사: “그런데 왜 전화한 내용은 안 말씀하셨어요?”
이서연: “무슨 얘길 했는지까지 다 말씀드려야 돼요?”
형사: “지금 확인하는 건 그거예요”
이서연: “저 그날 진짜 정신이 없었어요”
형사: “그 말은 정확히 몇 시부터예요?”

형사: “강도현 씨, 나갔다고 했죠?”
강도현: “네, 찍혔다면서요, 그 CCTV에”
형사: “다시 들어오진 않았습니까?”
강도현: “안 들어갔습니다, 제가 그 말을 왜 바꾸겠어요”

## 리스크가 있는 심문 행동
- 책상 내려치기: 손 모션-충돌 프레임-컵 물리-녹음기 SFX-상대 반응, 심문 시간/절차 신빙성 불이익. 자백 자동 확률 +XX 금지
- 침묵 유지: 무조건 승리 아님, 참지 못하는 사람도 있지만 오히려 법적 조언 요구 가능
- 주장 되돌리기: 형사가 이전에 공개하지 않은 자료를 ‘아는 척’하면 AI가 빈틈을 지적하거나 신뢰를 낮출 수 있음
- 자료 일부 공개: 용의자는 직접 읽은 정확한 범위만 앎
- 유도 질문: 녹취에 흔적이 남고 진술 신뢰성에 불이익, 법적 오류 검수
- 상대 변호인 요청: 조사 상황 및 법적 절차에 따라 즉시 적절히 중단/조정. 폭력이나 협박으로 강제로 조사 진행 금지

## 프로덕션 반드시 확인
- 실제 서버 LLM/Ollama 활성화 및 제공자 이름 노출 (개발자 콘솔만). 기본 Preview는 `SCRIPTED_PREVIEW_NOT_AI`이며 출시에서는 차단
- AI 응답 지연 P50/P95 측정, 한국어 최소 20~30턴×여러 시드에서 Persona/기억/정보벽 검증
- 의도하지 않은 정답 노출, 시스템프롬프트 탈취, 허위 목격, 허위 법적 기록, 고정 시각 변조를 자동/수동 검사
- 대사 QA: 한국인 사람이 듣고 1/10 이상 부자연스럽다면 출시 보류. LLM 문장 그대로 통과 금지
- 다양한 한국어 억양/속도/사투리 음성 입력 정확도 및 오인식 취소 실험
- 법률 및 절차는 설정 시점과 현행법 구별해서 형사 실무 감수 필요
