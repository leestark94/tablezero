# TABLE//ZERO — V11 최종 디렉션 / 이미지 품질 잠금

## 게임 정의
한국 생활공간의 1인칭 실사 범죄수사 + AI가 기억하고 판단하는 1:1 심문 + 플레이어의 판단이 사건을 바꾸는 심리 스릴러

> 형사는 범인을 의심한다, 범인은 형사가 무엇을 아는지 의심한다

이 프로젝트의 판매 포인트는 AI 챗봇이 아니다. 하나의 불변 사건 진실을 서로 다른 정보로 알고 있는 사람들이, 수사 중 서로에게 반응하고 그 결과가 다음 조사의 사실관계와 기회에 영향을 주는 것이다. GTA 6와 같은 실사 분위기는 목표 미학이지 이미 달성한 품질이 아니다

## 절대 잠금된 사용자 이미지
- `references_images/INTERROGATION_TARGET_VISUAL.png` — 사용자 채택 심문 화면 기준
- `references_images/SCENE_302_TARGET_VISUAL.png` — 사용자 채택 현장 화면 기준

두 이미지는 **아트 디렉션 레퍼런스**이며 **실제 Unity 플레이 장면의 증거가 아니다**. 캐릭터, 가구, 조명, 소품을 지금 프로젝트에 3D로 전부 보유하고 있다고 가정하지 말 것. 이미지들을 Unity 배경 평면에 붙이고 완성이라 주장하는 것도 금지

### 보존할 것
1. 심문실: 블랙/다크 브론즈/절제된 적색, 인물 손·상체의 긴장, 테이블 위 소품, 실제 조명 대비, 1:1의 위압감
2. 현장: 비좁은 한국식 원룸, 싱크대·방·화장실의 연속된 동선, 신발장, 음식 배달 흔적, 소음이 있는 창, 손전등의 빛과 1인칭 팔
3. 심문 인물과 공간은 어두워도 **정보가 안 보일 정도로 검지 않게** — 손/컵/서류는 보이게, 얼굴은 매번 똑같은 검은 실루엣이어선 안 됨
4. 과장된 영상 필터보다 보행과 반사·발소리·카메라 응시 후 무반응의 긴장 우선
5. 화면 구성은 참고 이미지 이상의 계층적 가독성: 영화 모드/자료 모드/심문 입력 모드가 분리

### 3D 제작 금지 규칙
- 퀄리티가 떨어지는 CC0 캐릭터·해외 경찰 템플릿·동그란 실린더 인물/침대/책상 배제
- Unity 기본 큐브·실린더·빈 캡슐을 실제 미술 에셋으로 **절대 승인하지 않음**
- 블록아웃은 별도 DEV_SCENE에서만. 사용자 승인 레퍼런스와 함께 출품·최종 데모 촬영 금지
- Blender에서 직접 작업 시 실측 치수 → 실루엣 → 상세 형상 → UV → PBR → 노멀/러프니스 → 리깅/모션 → Unity 실제 카메라에서 품질 확인 순
- Blender 화면만 예뻐도 Unity 인게임에서 저품질이면 실패. 앞모습/측면/접촉 프레임/어두운 조명/원근에서 반복 QA
- 혈흔, 지문, 구겨진 포장지, 컵 물방울, 테이블 긁힘 같은 고밀도 소품은 가까운 시선 20~40cm에서 재질과 촉각 이미지가 설득되는지 검사
- 물리적 일관성: 손이 사물 관통 금지, 문과 가구 충돌 금지, 손잡이 잡는 순간 IK와 SFX 정확 동기, 서랍 내부 실제 지오메트리 존재

## 의도된 반복 플레이 구조
- 고정: 진범·사건 원인·확정 과거 사실·객관 기록
- 달라짐: 질문 순서, 첫 의심, AI가 경찰의 지식에 대해 가진 추정, 목격자와의 관계, AI의 합법적 자율 행동, 확보 증거 순서, 임의 인터뷰 취소 여부, 보고서에 누락한 입증 축
- **고정된 진실과 동적 수사의 구분**이 게임의 근본. 재플레이를 위해 진범을 무작위로 변경하지 않는다
