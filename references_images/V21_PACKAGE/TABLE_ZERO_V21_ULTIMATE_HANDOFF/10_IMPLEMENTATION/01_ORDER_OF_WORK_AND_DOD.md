# Claude Code 구현 백로그 — 무엇을 어떤 순서로 끝내야 '게임'인가

## 왜 이 순서인가
스토리나 AI가 아무리 좋아도 메인 메뉴→현장→본부→심문→기록·포렌식→최종 보고→엔딩이 실제 빌드에서 작동하지 않으면 **데모가 아닌 장면 모음**이다. 반대로 UI 껍데기를 모두 만든 후 심문에 연결할 증거가 없으면 **게임 아닌 앱**이다. 따라서 코어 게임 루프와 스토리 근거를 끊어지지 않게 단계별 완성한다.

## P0 — 프로젝트 실물 감사와 정본 충돌 제거
**작업:** 실제 Unity 6 프로젝트의 컴파일·씬·그래픽파이프라인·UI·입력·LLM/음성·서버·현행 세이브·208 소품 프리팹을 조사해 표로 정리. Git 백업. V16 `culprit=s2` 및 `21:40 치명상` 로더 비활성. `V21_TRUTH`만 새 정본 로드.

**완료 근거:** 현재 작동 화면의 스크린샷, `git status`/diff, 충돌표, 208 매핑 진행률, 정본 로드 로그(정답은 공개 디버그 UI에 출력 금지). `P0_CONFLICT_REPORT.md`.

## P1 — 실제 메뉴→엔딩 게임 루프
**작업:** `BOOT`, `MAIN_MENU`, `CASE_SELECT`, `DISPATCH`, `INCIDENT_BRIEF`, `CORRIDOR_302`, `ROOM302`, `HQ_DESK`, `SUSPECT_ROSTER`, `INTERROGATION`, `FORENSICS`, `CASEBOARD`, `FINAL_REPORT`, `ENDING`을 **진짜 씬·패널·클릭·키 입력**으로 연결. 처음 사건 개요엔 확인된 내용만. 302호에 피해자 부재, 출동/사망/발견시간 구별.

**완료 근거:** 임시 텍스트/증거라도 오류 없이 메뉴→302→허브→심문→보고서→결말로 한 번 완주. 필수 버튼이 기능하지 않는 상태에서 디자인 완료 주장 금지.

## P2 — 비용·세계시계·저장·보고서
**작업:** 수사분 180, 행동 비용 표시·결제 멱등성·환불, WorldClock과 감식 회신 시프트 분리, 사건 수첩 및 4축 보고서. **찍기 승리 차단**. 한 번 제출, 편집 무제한, 0분에서도 제출/보류 가능.

**완료 근거:** `cost_committed=1회`, STT/AI 실패 0차감, 저장/로드 후 예산·문서·심문 기록 유지; 박 이름만 입력 시 성공 불가.

## P3 — 3인 공통 AI 심리·지식 엔진
**작업:** 캐릭터 바이블/Scene에서 사실을 읽어 독자적 기억 투영; 마이크/채팅 동일 Intent 경로; `OfficerBeliefModel`; 전술·회피·응답 계획; 한국어 표면 생성; ClaimLedger/권리·거부; 검증 실패 복구. **CASE 002에서도 공통 엔진 사용**.

**완료 근거:** 각 사람 50개 이상 질문 변형, 최소 1,000개 적대적 질문(또는 동일 수준의 충분한 자동 검증), 비밀 유출·자기 선제 자백·진범 전용 반응 없는 실제 로그. 환경상 테스트 규모 미달이면 실적/남은 것을 명시.

## P4 — 현장 상호작용 208 원본 최적화
**작업:** 각 행을 `CORE_HOTSPOT / CONTEXT_INTERACT / DECOR_STATIC / MERGE_INTERACTION / REMOVE_CANDIDATE`로 처리. 18개 주요 핫스팟의 실제 프리팹·관찰·문서·사진·회수·기록·심문/감식 연결. 13개 제거후보는 실제 씬 확인 전 보존.

**완료 근거:** 208/208 ID 소스 맵과 씬 별 사진, 핵심 18개 UX 접근 가능, 흔적/액자/폰/문서 3D 조작, 월패드 녹화 없음/복도 CCTV 화각 사실성.

## P5 — 19개 증거 체인 및 감식 실제 연계
**작업:** V21 evidence.json의 검출/한계/출처/감식 의뢰/회신을 구현. 피해자 폰 21:50 활동 원본 검증, 강 21:51 근무 기록, 서연 21:49 퇴장·21:55 카드 기록, 박 21:54 서류 연결. **독립 소스 및 오염/적법성 확인**.

**완료 근거:** 정답을 찍었는데 독립 증거 없는 경우 실패, 선량한 제3자 사생활/신고 거부로 자동 유죄되지 않음, 증거없는 LLM 대답으로 보고서 근거가 생성되지 않음.

## P6 — 22개 조건부 이벤트와 3D 인물 연기
**작업:** 사건 사실과 수사 상태가 일치할 때만 이벤트 한 번 발생. 서류 뒷장 반전, AI 역질문, 통화/면담 일정 변경, 감식 회신. 실제 3D 모델/애니메이션/음성자막/카메라 구도 연결.

**완료 근거:** 같은 이벤트 2회 발생 금지, 비밀 사실 선공개 금지, 시네마틱 스킵 후 수사기록 남음, 승인 이미지처럼 보이는 심문 화면, 스포일러 연기 없음.

## P7 — 밸런스/테스터/최적화
**작업:** 신규 테스터가 아무 설명 없이 처음부터 끝까지 45~70분 완주할 수 있는지 측정. 3개 플레이전략(적당한 심문·심문 편중·찍기)을 검증. Windows 1080p·2070SUPER 구동 프레임/지연/메모리 실측.

**완료 근거:** 프레임·STT/LLM 응답 지연·AI 누설 재현·소품 클릭 품질·데이터 저장·엔딩별 결과를 확인한 테스트 리포트. **미완료/우회 코드는 미완료**라고 기록.

## 작업 정의상 '완료' 아님
- Markdown만 생성했지만 코드는 미연결.
- 심문 UI만 있는데 로컬 AI 오류 처리가 없음.
- 사건명/브리핑만 보이고 302호 진입/엔딩이 없음.
- 208개를 한 번 눌렀을 때 “관찰 완료”라고 표시만 됨.
- CCTV가 파일명/대사로만 있고 원본 시간·화각을 검증하지 못함.
- 인물 고급 이미지만 있고 3D 리깅/모션/립싱크가 없음.
- '범인 맞춤' 선택만 하면 성공.
- 테스트 안 했지만 '컴파일 성공'이라고 서류에 쓴 상태.

**최종 정의:** 실제 Windows 빌드에서 플레이어가 **두 손으로 302호를 조사하고, 입으로 질문하고, 머리로 진술을 대조하고, 제한된 수사분을 쓰고, 자기 증거로 입증 보고서를 제출하는** 완전한 1개 사건. CASE 002는 001의 코드 복붙 없이 새 데이터로 구동 가능.
