# TABLE//ZERO V21.1 — FULL HANDOFF 릴리스 노트

**실제 사용자 요청:** CASE001 실감나는 한국형 악연·드라마, 고유 성격을 가진 세 AI의 자유 심문·역심문, 수사 행동 예산=돈, 208개 물품 최적화, 초동 사건 배정, 메인메뉴~엔딩까지 UI·UX/게임 루프 포함한 Claude Code 통합 마스터 프롬프트.

## 포함
- `01_CLAUDE_CODE_ULTIMATE_PROMPT.md` — 모든 설계 문서를 수렴하는 Claude Code용 명령(기존 V21 + V21.1 화면/QA 지시).
- `01_CANON` — 진범 박현수(s3), 피해자 포함 네 사람의 고정 사건 사실 **27개**.
- `02_DRAMA` — 네 인물의 성격/악연/과거와 장면 대본 **13개 본편 + 5개 추가 심문·후일담**.
- `03_AI` — CASE001~N 공통 AI 심리 엔진과 세 인물별 자세·말투·거짓말/반문·변경 응답 규칙.
- `04_EVIDENCE` — 증거 **19개**, 출처와 한계 및 4축 정식 입증 기준.
- `05_PROPS` — **208행 원본 전체와 분류 208행** (핵심 34항목/18묶음, 자연 조작 47, 배경 91, 중복 병합 23, 제거 후보 13).
- `06_EVENTS` — 조건부 돌발 연출 **22개**.
- `07_GAMEPLAY` — 수사분 **180** 초깃값/게임 루프/보고서.
- `08_UI_UX` — 메인 메뉴·시네마틱·사건 브리핑·현장·본부·수첩·심문·감식·자료·보고서·결말의 전체 화면 계약/와이어프레임/JSON 상태전이/**클릭 가능한 오프라인 HTML 시안**/초동 연출 대본/**112개 한국어 UI 문구**.
- `09_TECH_QA` — 물증 반증·코드권위 분리·CASE002 격리/구버전 충돌표/**129개 QA 사례** 및 정적 검사 Python.
- `10_IMPLEMENTATION` — 실제 Unity 구현 단계 및 완료/미완료 구분.
- `11_REFERENCE_ONLY` — 기존 사용자 승인된 심문실/용의자 호출 이미지(구버전 **텍스트·날짜는 시각 레퍼런스일 뿐 새 정본 아님**).

## 검증 상태
- 정적 원본-ID/참조/파일·텍스트 무결성: 패키지 검사 스크립트 통과.
- HTML의 인라인 JavaScript: `node --check` 문법검사 통과.
- **실제 Unity Play Mode/Windows 빌드/로컬 AI/STT/포렌식/성능 테스트는 미실행**. `QA_MATRIX.csv` `actual_result=NOT_RUN`은 의도적이다.

## 적용 시 절대 주의
- 과거 V16 `진범 이서연` 사건과 병합 금지.
- 기존 Unity 프로젝트를 이 ZIP으로 덮어쓰지 말 것. Claude Code가 실제 프로젝트를 열고 버전/에셋/미커밋 변경을 감사한 뒤 패치해야 한다.
- 가짜 'AI 프롬프트만 나열한 완료', 208물건 클릭노가다, 박현수 유죄 암시 연출, 무한 압박=자백, 범인 이름 찍기=승리, CCTV 마법 복원, 초동에서 범인·정확한 죽음 시각 공개는 불합격.
