## 3. 자유 진행 구조
`MENU -> INCIDENT_BRIEF -> HALL -> ROOM302 -> HUB -> (SCENE / INTERVIEW / LAB / RECORD REQUEST / CASEBOARD)* -> REPORT_DRAFT -> FINAL_SUBMIT -> ENDING`.
- 현장 첫 조사 강제 루트는 통제·관찰법 학습과 1~2개의 기록 정도만. 모든 물품 조사/모든 용의자 심문 의무화 금지.
- 3인 모두 실제 수사대상으로 등록되는 경로가 있고, 어느 사람부터 불러도 인물 지식/비밀이 동일하게 보존.
- 시프트: 2026.10.16 새벽 현장/예비수사, 다음 날 후속 자료/면담. 실제 대기시간과 플레이어의 수사행동 예산은 별도.
- 막다른 길 방지: 의복 감정을 못 받더라도 기록·진술·문서 검증으로 사건 인과를 입증하는 다른 조사 경로 지원. 압박 후 면담 종료돼도 객관 증거 경로 남김.

## 4. 수사분 = 단일 주요 자원 (V21 초깃값)
실제 플레이 목표 약 45~70분, 테스트로 튜닝. `action_budget=180`은 **게임 속 행동 자원**이며 현실 180분 플레이/경찰의 법정 수사 시한을 뜻하지 않는다.

|---|---:|---|
| 기존 증거 열람·현장 눈으로 보기·자유 노트 | 0 | 생각·읽기·모델 회전에는 비용 없음 |

180분을 다 쓰면 '보고서 제출/보류' 종료 처리. **아무 근거 없이 형사의 클릭을 기다리는 강제 제한 없음.** 시프트·분당 외부 사건 발생은 세계시계 `WorldClock`가 관리하고 사용자 입력 대기시간을 기준으로 지연시키지 않는다.

## 5. 실질적인 압박의 선택
- 일반 질문: 정보량이 적더라도 관계와 미세한 어조 확인. 경제적.
- 증거 제시: 추가 비용이 들지만 이전 진술과 대조할 근거가 있으면 가치 상승.
- 침묵 전술: 상대의 성격/피로/권리행사 상태에 따라 먼저 말하거나 조용히 기다리거나 면담 종료. 자동 비밀 누설 없음.
- 압박: 상대의 협조 저하, 방어적 반응, 변호인 요청, 상황에 따라 공개할 것 없이 위축될 수 있음. 고함 치면 범인 게이지 상승 같은 보상 금지.
- 책상 내려치기: 실제 애니메이션과 상황위험, 수사분 큰 차감. 유해·절차상 문제로 신문 결과의 증거 가치에 불리할 수 있음. 플레이어에게 비용/위험 고지.

## 6. 증거 노트/사건 보드
분리 UI: `원본 관찰` / `적법한 증거 채택` / `AI 진술·수정` / `확인 안 된 가설` / `연대기` / `사건 흐름` / `보고서 초안`. 
잘못된 가설(“이서연 옷 혈흔=치명상”)도 플레이어가 노트에 적을 자유는 있지만 엔진이 범인 확정으로 바꾸지 않는다. 반증이 나와도 자동 정답 힌트를 주지 않고 ‘기존 가설과 상충하는 자료’만 표시.

## 7. 최종 입증 & 찍기 방지
언제든 '박현수'를 가설로 표시 가능. 최종 보고는 단계 의무 진행이 아니라 **성립해야 하는 논증 조건**으로 통과.
1. **범행 시간/접근:** 피해자 21:49 이후 생존과 박의 21:54 전후 기회.
2. **동기/관계:** 허위 배송 책임 및 21:28 받은 구버전 서류.
3. **치명상 연결:** 두부 손상/저상 탁자, 사건 후 종이·의복·물리·연대기 다중 출처 검증.
4. **다른 두 사람의 설명 평가:** 강의 21:51 이후 실제 근무지, 서연의 21:49 퇴장 + 피해자 21:50 활동 등; 무죄를 자동 확정하지 말고 합리적인 대안 검증.

최종 보고서는 `소명한 주장→근거 원본→반대 자료에 대한 처리→불확실성`이 연결되어야 한다. 진범을 알고도 입증이 약하면 `CORRECT_UNPROVEN`, 오인 지목은 `WRONG_ACCUSATION`, 적법성 문제는 `PROCEDURAL_HOLD`, 보류는 `UNRESOLVED`, 탄탄한 보고면 `SOLVED_PROVEN` (게임 내 수사 성과, 재판 확정 판결 아님). 세 사람 중 누구를 지목해도 같은 근거 규칙 적용.

## 8. 플레이 리듬
첫 현장 7~10분 → 첫 AI 면담 8~15분 → 1차 기록/감식 5~8분 → 반전 진술/AI 역심문 10~15분 → 추가 조사/정밀자료 5~10분 → 재심문/보고 10~15분을 초기 목표로 둔다. **강제 타임라인이나 10분 컷신이 아니라 평균 플레이 흐름 가이드**. 지루하면 물품 숫자보다 의미 없는 재질문과 느린 로딩부터 줄인다.
