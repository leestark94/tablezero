# 플레이어가 실제로 선택하는 세 가지 수사 전략 / 180분 밸런스 초안

**기본 개념:** 행동 수사분 180은 전략 화폐다. 작중 날짜/감식 회신은 `WorldClock`에 따로 표시한다. 아래는 플레이테스트용 비용 시나리오이며 그대로 정답 스크립트로 하드코딩하지 않는다.

## A. 증거·심문의 균형형 — 충분한 시간을 남기고 범인 입증

| 행동 묶음 | 선택 예 | 소모 |
|---|---|---:|
| 현장 사진 | 휴대전화, 액자, 탁자, 정정서, 구급 흔적 | 5분 |
| 수거·봉인 | 현장 서류, 일부 물품, 휴대전화 | 9분 |
| 현장→본부 이동 | 1회 | 5분 |
| 첫 심문 | 강·이·박 3명 호출 | 18분 |
| 일반 질문 | 총 14개 의미 있는 질문 | 28분 |
| 증거 대조 | 5번의 명확한 물증 제시 | 15분 |
| 일반 기록 요청 | CCTV·사업장 근무 기록 | 12분 |
| 피해자 휴대전화 예비 분석 | 실제 원본 검증 신청 | 12분 |
| 문서 원본 관련 법적 자료 요청 | 수신자 쪽 문서 원본 절차 | 8분 |
| 탁자·상처 재구성 예비견해 | 별개 부상의 인과 구별 | 12분 |
| 박 추가 호출 | 문서/현장 물증 대조 | 6분 |
| 후속 일반 질문 | 4문항 | 8분 |
| 후속 증거 대조 | 3회 | 9분 |
| 현장 재방문 | 필요 시 1회 | 5분 |
| 압박 | 선택적으로 1회 | 6분 |
| **합계** | | **158분** |

**남은 22분.** 결과는 AI가 자백해야만 나오지 않는다. 필요한 원본의 무결성/후속 회신을 채울 수 있는지 반드시 실제 게임 테스트로 검증한다.

## B. 심문 중심형 — 증거의 효율적 공개가 중요
- 현장 사진 4, 3인 호출 18, 문서 봉인 6, 이동 10, 일반 질문 44(22회), 증거 대조 36(12회), 기록요청 14, 예비감식 24, 재호출 6 = **162분**; 남은 18분.
- **리스크:** AI의 진술이 모두 닫혀 있거나 필요한 핵심 원본을 놓치면 답변만으로는 끝나지 않음. 타임 리밋 직전에 무작정 압박하면 성공 확률이 높아지는 구조 금지.

## C. 찍기·감정 의존형 — 명백히 실패할 수 있어야 함
- 초반 이서연 소매 혈흔을 보고 서연 지목, 서연만 반복 호출 및 강압 → 많은 수사분 지출. `서연의 옷에 피해자 혈액이 있다`는 **접촉**의 근거일 뿐, `21:57 두부치명상`과 연결되지 않음.
- 박 이름을 우연히 찍어도 네 축의 독립 증거/진술/시간 검증 없으면 `CORRECT_UNPROVEN`.
- 강도현이 화내고 말을 돌린다는 이유만으로 강 지목하면 `WRONG_ACCUSATION`.
- 박이 침묵하고 변호사를 요구한다는 사실만으로 어떤 증거도 추가로 만들어지지 않음.

## D. 플레이테스트 후 수치를 어떻게 바꿀 것인가
- 타이핑/마이크 초심자가 코스트가 두려워 질문 자체를 안 하면 `일반 질문` 비용을 낮추거나 **연속 질문 번들(검증 가능한 주제/비용 표시)**을 제공하되 마이크 길이=비용 금지.
- 감식비가 너무 커서 누구도 의뢰하지 않으면 필수 감식의 접근 비용을 낮추고 후속 깊이 선택을 더 의미 있게 만들 것.
- 사진/봉인을 강제로 여러 번 눌러야 진도가 나가면 소품 상호작용을 합친다. 한 번 클릭으로 증거가 자동 인정되는 건 피하되 클릭 피로도는 줄인다.
- 실무 수사처럼 무엇을 확인하려는 행동인지 명확해야 하며, 시간 소모 앞에 가치를 이해시키는 UI 제공.
- 시나리오 성공률·플레이 타임·질문당 실제 의미 정보·반복 질문 비율·AI 오류/대기시간 등을 로그로 측정하여 비용표를 조정.

## E. 유저 스스로 정답을 깨달아야 하는 순간
**핵심 경험:** ‘이서연의 옷에 혈액’→그녀와 수연이 다툰 것은 사실→그런데 서연이 나간 뒤 수연의 음성/문서 활동이 확인됨→박이 그 이후 와서 서류에 관여한 정황→박의 최초 신고 진술을 검증할 추가 근거가 생김. 사건을 모두 설명하는 완벽한 단서 하나가 아니라, **정말 형사처럼 두 개의 물리적 충돌을 구분**하는 기쁨이 되도록 한다.
