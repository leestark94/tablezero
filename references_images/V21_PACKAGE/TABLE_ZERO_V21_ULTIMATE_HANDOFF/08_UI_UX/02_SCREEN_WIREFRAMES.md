# TABLE//ZERO — 8대 화면 배치 와이어프레임

> 화면 블록은 실제 픽셀 구성 전 **정보 구조** 기준. 구현은 `01_COMPLETE_GAME_UX_SPEC.md`와 동봉 승인 UI PNG를 함께 사용. 1920×1080에서 아래 비율을 기준으로 하되 화면 크기에 따라 재배치한다.

## 1. Main Menu — 정적 고품질 배경과 5개 버튼

```text
┌────────────────────────────────────────────────────────────────────────────────┐
│ TABLE//ZERO  ▏CASE FILES                              오래된 복도 / 실사 배경   │
│                                                                                │
│     [새 사건]                                               302호 현관         │
│     [이어하기]                                     형광등의 은은한 깜빡임      │
│     [사건 기록]                                                               │
│     [설정]                                                                    │
│     [종료]                                                                    │
│                                                                                │
│  로컬 AI: 연결됨    마이크: 선택 가능    Ver 21                            │
└────────────────────────────────────────────────────────────────────────────────┘
```

**새 사건**: 사건 선택 001. 사건 미해결 슬롯이 있으면 `새로 시작하여 덮어쓰기?` 확인. 002는 데이터/플레이 검증 완료 전 플레이 가능 표시 금지.

```text
┌────────────────────────────────────────────────────────────────────────────────┐
│ CASE001 / 박현수    녹음기 표시 / 작중 시간     수사분 118                        │
│┌─────────────────┐┌────────────────────────────────┐┌─────────────────────┐│
││  [종이 서류]     ││                                ││ 자유 질문 [기본]    ││
││  신원사진        ││      3D 박현수 / 어두운 조사실 ││ 증거 제시 3분       ││
││  기초 정보       ││                                ││ 침묵 전술 4분       ││
││  진술 탭         ││        눈·손·호흡·표정         ││ 압박 질문 6분       ││
││  관련 증거 탭    ││                                ││ 책상 행동 12분      ││
││  형사 메모       ││                                ││ 진술 기록          ││
│└─────────────────┘└────────────────────────────────┘└─────────────────────┘│
│       [용의자 실제 답변 자막 / 발화 중 자연스러운 애니메이션]                  │
```

- 고정 대사창보다 **마이크/텍스트 입력 우선**. STT 인식 완료 후 수정/전송; 유효 응답 이후 비용 차감.
- 심문 종료 후 동료 보고서로 자동 정답 설명 금지. 같은 진술 원본만 사건 보드에 보존.
- 왼쪽 스크롤로 인물 정보 확인 중에도 질문 중단되지 않아야 하며, 심문 AI가 왼쪽에 공개되지 않은 숨겨진 파일을 읽지 못함.

## 9. Ending
- **성공:** 증거/진술 기록과 수사 결론을 인계; 사고 전 함께 웃던 네 사람 사진이 다시 등장. 어색한 '정답입니다!' 효과음/범인 확률 공개 금지.
- **오인:** 불충분한 근거로 다른 사람을 밀어붙인 수사의 무게를 보여주되 법원의 확정 판결처럼 표현하지 않음.
- **미입증:** 이름을 알아맞혀도 자백/정황만 있으면 사건 수사 의견 보류.
- **재시도:** 사건 재시작, 결과 보존/회차 구분; 실패한 유저에게 뒷이야기를 자동 스포일러하지 않음.
