## 1. 기존 작업을 없애지 않는 것이 전제

- `git status` 저장, 소스/ProjectSettings/Packages/Assets/Server/Tests 백업, 브랜치 체크포인트 뒤 변경. 사용자 승인 전 외부 API 결제·새 유료 에셋 구매 금지.
- 현재 작동 중인 302호 3D 아트와 좌측 서류/우측 용의자 심문 배치는 반드시 보존, **기능 버그와 실제 사건 스토리 충돌만 패치**.
- 원본 ID 208개 그대로 읽되 제거 후보 13개는 삭제가 아니라 **QA 후 검토**. 머지 대상 23개는 자산/물리 개체 삭제 없이 클릭 영역 통합 가능.

## 3. 자동으로 하지 말아야 할 것
- 이전 `s2` 정답 필드를 공통 JSON에 남겨두고 새 `s3`와 공존시키는 것.
- Unity UI에 구버전 날짜 `2024.03.16`, '302호 살인사건' 확정 표기를 그대로 두는 것.
- `박현수` 진범을 시각적으로 빨간 고유 효과로 강조하는 것.
- 구버전 V11의 '모든 208개 클릭 필수', V15의 '감식 세 번', V17의 '예약 공지' 등을 새로운 엔진과 병용하는 것.
- V19/V20 대사 문장을 LLM의 고정 대답으로 붙여놓고 '자유 심문'이라고 부르는 것.
- 강/서연의 가해행동과 박의 치명상을 하나로 합치는 것.
- 119 구급대가 남긴 바닥 자국을 범인 조작 흔적으로 무조건 채택하는 것.
- 녹음기나 카메라를 실제 Unity 렌더와 다른 위치/각도에 있는 것처럼 꾸며내는 것.
- 박의 거짓말이 발각되었다는 이유만으로 곧바로 폭력 자백 이벤트를 실행하는 것.

## 4. 실제 마이그레이션 순서
1. 현재 파일·프리팹·씬·사실 정본·코드 진입점을 전수 파악. `CURRENT_PROJECT_AUDIT.md`에 완료/미완료/버그 표.
2. `V21_TRUTH` 전용 loader, 기존 V16 정본 loader는 차단. 구버전 `culprit_id`, `claim_id`, `fact_ids`, `evidence_ids`를 추적해 참조 교체.
3. 사용자 승인 302호/심문/용의자 호출 UI는 스크린샷 비교하며 그대로 유지. UI에 표시되는 이름/날짜/진술/판정만 교체.
4. 기존 소품 208 원본 ID → `PROP_208_V21_CLASSIFICATION.csv`와 실물 prefab path를 매핑. 공유 메시/겹침/제거 후보는 변경 전에 QA.
5. 18 주요 조사 묶음/19종 증거를 이펙트가 아닌 실물·원본과 연결.
6. 전체 게임 흐름 + 수사분을 먼저 완주 가능하게 만든 뒤, 3인 인격·음성·회신 이벤트를 통합.
7. 스토리 충돌/거짓말 누설/타인 지식 유출/보고서 찍기 테스트 수행. `MIGRATION_CONFLICTS_AND_DECISIONS.md`에 기존 동작/수정 이유/검수 기록 남김.
8. Windows 빌드 실제 테스트, UI 스크린샷·영상·로그·성능·회귀 결과 제출. 실제로 측정한 것만 합격 선언.

## 5. 출시/공개 전에 반드시 확인할 현실성
- 실제 한국의 형사 절차, 증거 제출·압수·통신자료/금융정보 확보의 법적 요건.
- 피해자의 손상 형태, 탁자 높이/동선/신체 부상과 생존 시간의 현실성. 드라마 설계용 사망시각은 의료 조언 없이 공식 사실처럼 홍보 금지.
- CCTV 실제 화각, 로그시간 일치, 편의점까지 이동시간, 강의 근무지 거리와 출입·작업 확인.
- 박의 거짓말 증거가 어느 수준으로 인정되는지; 301호 자료 취득의 수사절차.
- AI가 유료 서버 호출 없이 로컬로 가능한 품질과 RTX2070SUPER 동시 구동 성능. 유료 모델 필요 시 사용자의 사전 동의 필수.

## 6. 이번 명세와 실제 개발 사이의 경계
이 ZIP은 **실제 Unity 프로젝트를 수정한 결과가 아니라**, 원본 대조한 설계/지시/UX 시제품 패키지다. 클로드에게 구현 명세를 전달했다고 사용자의 게임 코드가 변한 것은 아니다. `04_CLICKABLE_UX_PROTOTYPE.html`은 진짜 Unity나 AI가 아니라 클릭하는 레이아웃 시안이다.
